# Uncertainty_on_Antarctic_SIC

This repository provides SMRT and PARMIO model configurations for mixed-pixel simulations of sea ice. 
The Output folders contain:

1) Brightness temperature variability results for varying ocean and snow-covered sea ice physical properties
2) Sensitivity analysis results from the Bootstrap algorithm core

For details, see: https://doi.org/10.5194/egusphere-2025-6437.
